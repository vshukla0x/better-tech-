# Better Tech - OS Recommender[cite: 1]

An interactive web application designed to help developers and system enthusiasts determine the most suitable operating system based on workflow constraints, hardware needs, and software requirements[cite: 1].

---

## Features

- **Interactive Filtering:** Matches operating systems based on workflow requirements and technical criteria[cite: 1].
- **Developer-Focused Options:** Categorises distributions and systems suited for development, sysadmin tasks, and daily computing[cite: 1].
- **Lightweight Interface:** Clean, low-latency UI for rapid filtering and comparisons.
- **Rule-Based Engine:** Deterministic logic evaluating user parameters against operating system characteristics.

---

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (or specify framework, e.g., React / Vite)
- **Logic:** Client-side rule engine
- **Deployment:** Vercel / GitHub Pages
